# NFL Data Analysis Project

## Project Structure
- `data/raw/`: Original data files
- `data/processed/`: Cleaned and processed data
- `scripts/`: Python scripts for scraping and processing
- `output/`: Analysis results and outputs
- `notebooks/`: Jupyter notebooks for exploration

## Data Sources
1. Pro Football Reference (pro-football-reference.com)
2. Kaggle Datasets
3. Official NFL APIs
4. ESPN Stats

## Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Run scraper: `python scraper_nfl.py`
3. Process data: `python process_data.py`

## Scripts
- `scraper_nfl.py`: Scrapes stats from various sources
- `scraper_nfl_v2.py`: Alternative scraper with retries
- `scraper_nfl_selenium.py`: Browser-based scraper
